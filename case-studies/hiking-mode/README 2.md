# Hiking Mode Case Study Site

Scrollable portfolio narrative for **Google Maps Hiking Mode**. Research docs remain the source of truth under `../docs/`.

## Quick start

```bash
cd case-study
npm install
npm run dev
```

Opens on **http://localhost:5174**.

For the interactive Hiking tool CTA, also run the web prototype on port 5173:

```bash
cd ../web
npm install
npm run dev
```

## What’s on the page

Problem → synthesized research (F1–F6) → decision → personas/journey → define → happy paths (H1–H3 must-work behaviors) → Solution (Google Maps Hiking Mode features + hi-fi) → capabilities → prototype links → validation / open assumption.

## Scripts

| Command | Purpose |
|---------|---------|
| `npm run dev` | Local narrative site (port 5174) |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build |
