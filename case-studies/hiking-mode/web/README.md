# Hiking Mode — Hi-Fi prototype

Phone-framed clickable Google Maps Hiking Mode screens (Solution fidelity).

```bash
npm install
npm run dev
```

Open **http://localhost:5173**.

## Flow

1. Home Search → Try Hiking mode  
2. Mode Switcher → Start in Hiking mode  
3. Trail-first Map → Steps / Day plan  
4. Multi-day Corridor → Open Day 2  
5. Day Plan ↔ Elevation  
6. Offline Pack  
7. Safety Share → Back to trail map  

**H1 / H2 / H3** chips jump Corridor ready / Trust the fork / Recover.
